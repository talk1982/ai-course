סיכום שיעור 1: מבוא לפייתון ו-AI

עם מאיה מלמוד

למה פייתון ל-AI?

  • **אוטומציה:** ביצוע פעולות חוזרות (רפטטיביות) ללא התעייפות.
  • **חישובים כבדים:** מצוינת למתמטיקה מורכבת הנדרשת ב-AI.
  • זו "השפה של AI": כל הכלים המרכזיים (TensorFlow, LangChain) כתובים בה.
חובה לעבוד עם פייתון 3 ומעלה!

סביבת עבודה: VS Code

סביבת הפיתוח המרכזית (IDE) של הקורס תהיה Visual Studio Code.

  • פתיחת תיקיות ויצירת קבצים.
  • קבצי פייתון מסתיימים תמיד ב-.py
  • אינטגרציה מלאה עם כלים כמו GitHub Copilot.

הרצת קוד ב-VS Code

ניתן להריץ קוד ב-VS Code בכמה דרכים:

  • דרך כפתור ה-"Play" (הרץ קובץ פייתון).
  • ב-"Interactive Window" להרצה חלקית.
  • **הרצת "תאים" (Cells):** ניתן לחלק קובץ `.py` לתאים באמצעות הערה מיוחדת:
# %%
print("זהו תא ראשון")

# %%
print("זהו תא שני")

עוזר AI: GitHub Copilot

כלי עזר להשלמת קוד אוטומטית. מקבלים הצעה ע"י כתיבת הערה (עם `#`) ואישור ההצעה עם `Tab`.

# list all prime numbers from 1 to 100
# (לחץ Tab ו-Copilot יכתוב את הקוד)
**אזהרה (Hallucination):** הכלי עלול "להמציא" קוד שגוי במשימות מורכבות. חובה לבדוק אותו!

משתנים (Variables)

  • **כללי שמות:** אותיות, מספרים ו-_. אסור להתחיל בספרה.
  • **השמה (Assignment):** name = "Osnat"
  • **השמה מרובה:** x, y = 3, 2
  • **השמה מחדש (דינמית):**
number = 2       # number הוא int
number = "hello" # עכשיו number הוא str

סוגי נתונים (Data Types)

  • int: מספר שלם (למשל 10)
  • float: מספר עשרוני (למשל 2.3)
  • bool: אמת / שקר (True / False)
  • str: טקסט / מחרוזת (למשל "Hello")
  • list: רשימה (למשל [1, 2, 3])
  • complex: מספר מרוכב (3 + 2j)

פונקציות בסיסיות

פונקציות מובנות (Built-in) נפוצות:

# הדפסה למסך
print("Hello World")

# בדיקת סוג משתנה
type(10)  # יחזיר: 

# בדיקת אורך (מספר איברים)
len("hello")  # יחזיר: 5

אופרטורים אריתמטיים

פעולות חשבון בסיסיות על מספרים:

  • + (חיבור), - (חיסור)
  • * (כפל), / (חילוק רגיל)
  • ** (חזקה): 3 ** 2 זה 9
  • // (חילוק שלמים): 7 // 2 זה 3
  • % (מודולו - שארית): 7 % 2 זה 1

טקסט (String): יסודות

  • **הגדרה:** '...', "...", או """...""".
  • **בדיקת הימצאות (in):** בודק אם טקסט קיים (רגיש לאותיות).
# שרשור
"Hi" + " " + "Maya"  # תוצאה: "Hi Maya"

# שכפול
"Go! " * 3    # תוצאה: "Go! Go! Go! "

# בדיקה
"a" in "Maya"   # תוצאה: True

f-strings (עיצוב טקסט)

הדרך המודרנית לשלב משתנים בטקסט. מוסיפים f לפני המרכאות ומשתנים בתוך סוגריים מסולסלים {}.

name = "Osnat"
age = 32
print(f"Hello {name}, you are {age} years old")
# תוצאה: Hello Osnat, you are 32 years old

אינדקסים (Indexing) וחיתוך (Slicing)

כלל הזהב: הספירה מתחילה מ-0!
  • **גישה לתו:** my_string[0] (התו הראשון)
  • **מהסוף:** my_string[-1] (התו האחרון)
  • **חיתוך [start:end]:** הערך ב-end *אינו נכלל*.
foo = "foobar"
foo[0:3]  # תוצאה: "foo" (אינדקסים 0, 1, 2)
foo[3:]   # תוצאה: "bar" (מ-3 עד הסוף)

פעולות (מתודות) על סטרינג

פעולות נפוצות לניקוי ושינוי טקסט:

text = "  Hello World  "
text.strip()       # תוצאה: "Hello World"
text.replace("o", "a") # תוצאה: "  Hella Warld  "
text.split(" ")    # תוצאה: ['', '', 'Hello', 'World', '', '']
text.upper()       # תוצאה: "  HELLO WORLD  "
text.lower()       # תוצאה: "  hello world  "

רשימות (List): יסודות

אוסף סדור של איברים בסוגריים מרובעים []. יכול להכיל סוגי נתונים שונים וכפילויות.

# רשימה ריקה
empty_list = []

# רשימה עם סוגים מעורבים
my_list = [1, "hello", True, 2.5]

# גישה עם אינדקס
print(my_list[1])  # תוצאה: "hello"

פעולות על רשימה: הוספה

my_list = [1, 2, 3]

# הוספת איבר אחד לסוף
my_list.append(4)
# my_list עכשיו: [1, 2, 3, 4]

# הוספה במיקום ספציפי (אינדקס 0)
my_list.insert(0, "start")
# my_list עכשיו: ["start", 1, 2, 3, 4]

# הוספת איברים מרשימה אחרת
my_list.extend([5, 6])
# my_list עכשיו: ["start", 1, 2, 3, 4, 5, 6]

פעולות על רשימה: הסרה

my_list = ["a", "b", "c", "d"]

# הסרה לפי ערך (מוחק את 'b' הראשון)
my_list.remove("b")
# my_list עכשיו: ["a", "c", "d"]

# הסרה לפי מיקום (מוחק את האיבר האחרון)
last_item = my_list.pop()
# last_item: "d"
# my_list עכשיו: ["a", "c"]

# הסרה לפי מיקום (אינדקס 0)
first_item = my_list.pop(0)
# first_item: "a"
# my_list עכשיו: ["c"]

רשימות מקוננות (Nested)

רשימה יכולה להכיל רשימות אחרות בתוכה, ליצירת מבנה דמוי-טבלה (מטריצה).

nested_list = [ [1, 2, 3], [4, 5, 6] ]

# גישה לאיבר
# קודם ניגשים לרשימה החיצונית (אינדקס 1)
# ואז לרשימה הפנימית (אינדקס 0)
print(nested_list[1][0])

# תוצאה: 4

פונקציות עזר (Debug)

שתי פונקציות שימושיות לבדיקה וחקירה של משתנים ופונקציות:

my_string = "hello"

# dir() - מציג את כל הפעולות האפשריות
print(dir(my_string))
# תוצאה: [... 'upper', 'lower', 'strip' ...]

# help() - מציג את התיעוד על פעולה
help(my_string.upper)
# תוצאה: ...Help on built-in method...

מילות מפתח שמורות

אלו מילים שאסור להשתמש בהן כשמות של משתנים, כי יש להן משמעות מיוחדת בפייתון.

# אסור לעשות:
# if = 5
# while = "hello"
# True = False

import keyword
print(keyword.kwlist)
# תוצאה: ['False', 'None', 'True', 'and', ...]
